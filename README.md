# Axis Knowledge Vault

个人技术知识库与 GitHub 趋势情报仓库，面向 Obsidian、ChatGPT 自动化与 Axis 系列项目长期积累。

## 目录

- `00 Inbox/`：临时收集，待整理内容。
- `10 Projects/`：AxisAgent、AFSCADA、AxisMusic 等项目知识。
- `20 Technology/`：C#、.NET、WinUI、Avalonia、AI 等长期技术主题。
- `30 Intelligence/`：GitHub Trending、生态变化、工具与开源项目情报。
- `80 Templates/`：Obsidian 笔记模板。
- `90 Archive/`：归档内容。

## GitHub Trending 自动化

每日趋势写入：

`30 Intelligence/GitHub/Daily/YYYY-MM-DD.md`

长期主题索引：

- `30 Intelligence/GitHub/Agent.md`
- `30 Intelligence/GitHub/DotNet.md`
- `30 Intelligence/GitHub/WinUI.md`
- `30 Intelligence/GitHub/Avalonia.md`
- `30 Intelligence/GitHub/Local-AI.md`

自动化原则：

1. 不机械收录榜单，只保留有技术价值或趋势意义的项目。
2. 优先关注 Agent、AI Coding、MCP、Skills、Context/Memory、Browser/Computer Use、C#/.NET、WinUI 3、WPF、Avalonia、Rust Desktop、本地 AI。
3. Daily 记录当天证据与判断；主题页维护长期趋势和可复用结论。
4. 使用 YAML frontmatter、`[[双向链接]]` 和 Obsidian 兼容 Markdown。
5. 避免重复条目；同一项目后续变化优先更新既有知识链。

## 本地使用

将本仓库 clone 到 Obsidian Vault 目录，或直接将仓库根目录作为 Vault 打开即可。
