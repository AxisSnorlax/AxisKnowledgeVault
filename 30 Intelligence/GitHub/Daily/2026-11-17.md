### P1 — SkillEvaluator：检查通过还需要说明通过了什么

[当前 README](https://github.com/NVIDIA/SkillEvaluator) 区分静态质量、扫描和 live agent evaluation；静态示例可以退出成功，但发布证据仍为 INCOMPLETE。组合 `validate` 中，Tier 3 只有显式设置 `--block-on-agent-eval` 才参与阻断。

[v0.9.0](https://github.com/NVIDIA/SkillEvaluator/releases/tag/v0.9.0) 页面显示 11 月 13 日，区分与旧技能版本比较、与无技能基线比较，并保留预算耗尽后的部分结果。该版特别说明：生成的 all-tier CI 中 Tier 3 仍为 advisory，旧的 required 配置不再将它变成必需门槛；这与独立验证命令的开关是不同执行入口。

工程推论：审计回执同时记录评估入口、实际门槛、基线身份及未完成范围，不能只保存总分。详见本轮追加的 [[Agent Skill Supply Chain]]。上述为项目文档声明，本轮没有运行评估器或向外部模型发送技能内容。

### P2 — OpenCodeReview：低噪声审查仍需单独核对漏检

[OpenCodeReview README](https://github.com/alibaba/open-code-review) 描述确定性文件筛选、规则匹配和评论定位与 LLM 上下文检索相结合的审查流程。作者报告的基准强调精确率、F1 和成本，同时明确其召回率低于对照通用 Agent；采用低噪声取舍不意味着发现了所有缺陷。

这是项目自报评测，未独立复现。对 [[AxisAgent]] 的推论：保存实际审查文件集合、规则范围、未覆盖原因和可复核的代码位置；没有评论不能代替编译、测试及安全扫描通过。这里不把主分支文档中的能力推定为某个未核对发行版已提供，也不运行仓库给出的安装命令。

### P3 — Omnigraph：升级会改变 MCP 可调用操作面

[Omnigraph v0.15.0](https://github.com/ModernRelay/omnigraph/releases/tag/v0.15.0) 页面显示 11 月 9 日。该版取消隐藏 MCP 工具的服务端开关，将图操作交由 Cedar policy 决定；MCP 工具复用对应 HTTP 路由及 action。Blob／导出的字节流仍留在 HTTP 与 CLI。即使之前没有设置 MCP 开关，升级后 Agent 也能获得策略允许的新增工具。

工程推论：升级审核应比较实际暴露的操作及对应权限，不能根据旧工具列表推断只读范围。发布页中的存储请求数来自模拟内存存储，CSV 导入耗时来自作者本地 Apple 工作站，未测 S3 导入；本轮不将这些数字当作 Windows 或真实 S3 部署的独立性能结论。沿用 [[Agent Capability Policy Enforcement]]，不重复追加泛化原则。

## C#/.NET — OfficeCLI 的结构正确性

[OfficeCLI v1.0.161](https://github.com/iOfficeAI/OfficeCLI/releases/tag/v1.0.161) 页面显示 11 月 12 日：修正 xlsx 新增 `dxfs` 在 `tableStyles` 和 `colors` 之前的元素顺序、为 pptx 实例化的版式对象分配唯一 ID，并改进英文换行。

Windows/.NET 文档工具的借鉴：除了视觉预览，还需验证格式结构、对象身份和重新打开后的内容。界面看起来正常不能单独证明生成文件符合格式约束。该结论是从修复项得到的工程推论，本轮未编辑 Office 文件或执行 .NET 构建测试。

## 本地 AI — OpenUtau 的后端边界

[OpenUtau](https://github.com/openutau/OpenUtau) 是跨 Windows、macOS、Linux 的歌声编辑工具，包含 WORLDLINE-R 并支持 ENUNU 等歌声后端。[0.1.576](https://github.com/openutau/OpenUtau/releases/tag/0.1.576) 页面显示 10 月 20 日，是本轮 latest 入口返回的既有版本；记录 vogen 渲染固定使用 CPU、worldline 内存泄漏修复，以及加载项目时停止渲染。

对本地 AI 桌面应用的推论：模型／音源、渲染器和执行设备分别记录，取消、载入新项目与资源释放需要明确交接。不能从某个后端的 CPU 或 DirectML 配置概括整个应用；本轮没有加载音源、验证音质或测量 GPU 加速。
