## P1 — DBX：准确预览的适用范围

[v0.6.74](https://github.com/t8y2/dbx/releases/tag/v0.6.74) 页面显示 11 月 24 日。其 [#15545](https://github.com/t8y2/dbx/pull/15545) 指出：旧预览把所有赋值表达式都放在旧行上计算，但 MySQL 单表 UPDATE 中后续赋值可能读取前面刚更新的列，因此预览会显示错误的新值。

修复对读取同一语句中较早赋值列的指定场景拒绝预览；独立赋值及其他说明范围保持原行为，用户仍可执行原语句。上游记录了聚焦检查，本轮未独立复测，也不把该拒绝行为描述成禁止 SQL 执行。

Windows/.NET 专业软件的推论：预览保留操作身份、来源版本、方言／引擎语义及未覆盖范围；无法可靠模拟时明确返回不可用。预览通过也不能代替执行后的读回验证。该增量写入 [[Professional Software Agent Surface]]，本轮没有连接数据库或执行 SQL。

## P2 — DBX MCP：连接身份与实际传输路径

同版收录 [#15549](https://github.com/t8y2/dbx/pull/15549)：通过已保存连接调用插件时，先解析宿主管理的运行时端点及可选代理路径，保留原服务器逻辑身份用于 SSH host-key 校验；传输准备失败会传播错误，不静默回退直连。

工程推论：UI 与 MCP 使用同一保存连接时，应核对实际路由和目标身份是否一致。端点准备、认证身份及权限决策分别记录，不能把代理隧道的临时地址当成原服务器身份。这里依据已合并 PR 和发行说明，不宣称已在用户网络环境验证；沿用 [[Agent Capability Policy Enforcement]] 与 [[Durable Agent Runtime Identity]]。

## WinUI / C# — FluentCleaner 的默认规则与已有状态

[26.11.123](https://github.com/builtbybel/FluentCleaner/releases/tag/26.11.123) 页面显示 11 月 23 日。发行说明指出，过去开启 Winapp3 会默认勾选包括较大删除范围的规则；新默认取消这些勾选，但已有选择仍保留，直到使用者明确恢复默认状态。Web Storage 的默认值也有类似变化。

同版区分 Analyze 与真正清理，清理后按条目展示实际释放结果；Custom 保存失败时保留对话框内容，并修复重命名覆盖和禁用项目被编辑后重新启用的问题。作者还移除了 Custom 中缺少分析／预览的 PowerShell 运行入口。

对 Windows 工具的借鉴：新版默认策略和已持久化用户选择是两种状态；扫描、拟执行范围、跳过项及真实效果分别展示。缓存、包仓库、会话历史和备份具有不同恢复成本，不能统一当作临时数据。本轮没有运行清理、恢复默认值或修改本机文件选择。

## Agent / AI Coding — 重试需读取具体错误含义

[Rig v0.47.0](https://github.com/0xPlaygrounds/rig/releases/tag/v0.47.0) 本轮 latest 仍是 11 月 20 日版本。除已记录的摘要条件提交外，它明确将部分 provider 错误代码判为终止，即使 HTTP 状态通常可重试；摘要调用的重试也遵循内核策略和 provider 等待要求。

工程推论：重试决策不能只依据 HTTP 状态码；保留 provider 原始错误、请求阶段和实际尝试次数。此项延续 [[Agent Verification and Audit Plane]] 的错误来源判断，不重复追加。

[last30days v4.6.0](https://github.com/mvanhorn/last30days-skill/releases/tag/v4.6.0) 本轮仍返回 11 月 22 日发行；成稿捕获、离线回填和来源保留已在 11 月 23 日记录，没有新证据足以更改 [[Agent Memory and Knowledge Lifecycle]]。本轮没有采集用户历史或安装 hook。

## 本地 AI — Jan 的本地与远端路由

[Jan v0.8.8](https://github.com/janhq/jan/releases/tag/v0.8.8) 仍是本轮 latest 返回的既有版本。其发布说明区分对自身引擎的直连与远端 provider 的代理路径，并将本地 API 可调用与服务端 MCP 执行开关分别处理。

这与 DBX 的新传输修复形成可比较样本：路由应遵循每类目标的明确配置，而不是全局套用“总是代理”或“失败直连”。对 [[Local-AI]] 继续保留引擎／模型／端点身份和请求回执，本轮没有更改代理、模型或缓存。
