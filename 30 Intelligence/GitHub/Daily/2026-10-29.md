### P1 — ILSpy：短命令启动与完整任务成本分别看

[ILSpy 11.2 发布页](https://github.com/icsharpcode/ILSpy/releases/tag/v11.2) 显示 10 月 27 日，新增 win-x64、linux-x64 的 `ilspycmd` Native AOT 包。维护者以同一个约 3 MB 输入在 win-x64 上报告五次运行中位数：版本查询从 219 ms 降至 45 ms，完整项目反编译则从 6.3 s 降至 2.9 s。这是项目自报，未在用户机器复测，也不能推广为所有命令相同比例的收益。

同一发行记录列出程序集解析、文化环境与 AOT 输出保真相关改进，提醒性能必须与结果一致性同时验收。对 [[AxisAgent]] 的设计推论：工具版本、发布形态、平台和调用任务进入同一测量记录；高频小调用与整批任务分别比较，并核对诊断、错误和输出。补充到 [[30 Intelligence/GitHub/DotNet|.NET / C# 趋势索引]]。

### P2 — Uzu：后端列表与可交付平台不能混为一谈

[官方 README](https://github.com/trymirai/uzu) 描述 Rust 引擎、多语言绑定、可追踪计算与模型配置。Development 中列有 Metal、WebGPU、CPU，但 Windows x64 与 ARM64 目标仍标为 in progress；不能从“有 WebGPU/CPU 后端”推出当前 Windows 包已经可用。

[0.6.13](https://github.com/trymirai/uzu/releases/tag/0.6.13) 页面显示 10 月 22 日，返回带两日前的抓取缓存，且该页仅提供简短版本说明。本轮不将其当作今天的新发布或完整功能变更清单。

对 [[AxisAIManager]]，可研究它的模型配置与计算追踪方式，但需分别验证目标平台、绑定、模型转换和正确性。其自有模型格式也不能直接当作现有 GGUF 目录的无条件替换。项目宣传的低延迟与隐私能力是自述，本轮不作本机性能或数据流验收。

### P2 — Microsoft MCP：目录不是单一服务器版本

[根目录说明](https://github.com/microsoft/mcp) 区分从该仓库构建的 Azure/Fabric 服务与更广泛的 Microsoft MCP 目录；条目同时包括本地进程和远程端点，也包含独立仓库的服务。它是发现与工程复用入口，不能以仓库品牌替代具体服务的运行合同。

[Azure MCP README](https://github.com/microsoft/mcp/blob/main/servers/Azure.Mcp.Server/README.md) 的功能示例同时包括查询、创建、更新与删除。对 Windows/.NET 客户端，必须按实际服务版本、工具 schema、账户与操作范围处理权限，而不是将“官方 MCP”统一视为只读。该页属于当前 main 文档，不表示用户已经安装或启用这些能力。

Azure 的 CHANGELOG 页面本轮只返回文件元数据，没有展示正文，因此不宣称已完成其最新版本逐项核验。本轮未连接云账户、配置 MCP 或调用这些业务工具。

## 长期判断

1. **启动成本与完整任务成本分别测量。** 比较需要一致输入、平台、命令和发布形态，维护者数字不能替代目标机数据。
2. **优化必须保留语义。** 程序能启动或更快结束，不代表解析、诊断与输出正确性未变。
3. **平台支持与工具权限按具体对象判断。** 后端清单、仓库目录和协议兼容名称都不能替代真实制品及运行合同。
