## 今日最值得关注的变化

### P0｜microsoft/mxc — Windows 原生 Agent 隔离正式发布

- **方向**：Rust 核心、Windows/Linux/macOS sandbox；.NET/Rust/Node SDK。
- **增长信号**：Rust Daily Trending 约 +106 stars today；更重要的是 Microsoft 于 **2026-10-07 宣布 Microsoft Execution Containers（MXC）Generally Available**。
- **原始资料**：https://github.com/microsoft/mxc
- **值得看**：统一容器请求/Policy，按平台选择 ProcessContainer、Windows 独立 Session、WSLc 等后端；文件、网络和 UI 权限在外部运行时边界生效；.NET SDK 支持一次性任务与 provision/start/execute/stop/deprovision 生命周期。
- **Windows/.NET Agent 借鉴**：将 Capability/Approval 与真正的 **Execution Sandbox Adapter** 分离；研究 native ProcessContainer 是否可作为 [[AxisAgent]] 的可复用执行边界。确认文件只读/拒绝、网络及 loopback、GUI/Clipboard、PTY/IO、超时和故障回收的实际行为。
- **限制**：GA 不代表每一台 Windows 已具备相同隔离能力。目标机必须按实际 OS Build、补丁和后端能力做探测；必须验证 fail-closed、权限降级、取消、并发、状态回收和异常退出。
- **长期关联**：[[Agent Capability Policy Enforcement]] · [[Deterministic Agent Runtime]] · [[AxisAgent]] · [[DotNet]]。

### P1｜openai/codex-security — 独立验证成为可组合的安全检查流水线

- **方向**：AI Coding / 代码检查 / 证据与报告。
- **信号**：当前不是爆款日增长，但与 2026-10-08 Cloudflare 安全审计 Skill 的独立验证趋势相互印证。
- **源仓库**：https://github.com/openai/codex-security
- **为什么看**：支持 repo/path/Git diff 范围、并行分析、候选结果验证、补丁验证、去重、Threat Model、coverage gaps、SARIF/JSON/CSV 与 CI。
- **Windows/.NET 借鉴**：Verification Result 至少应包含 scope、coverage、sourceRevision、finding status、severity、evidence、SARIF Artifact；与 .NET Build/Test 和静态分析形成独立门禁。
- **边界**：没有发现不等于安全；第二个 Agent 的判断不能自动等价于 PASS。

## 今天形成的架构决策

1. **MXC GA + .NET SDK 改变了此前 Windows 原生 Agent 隔离仅有实验路径的判断。** 在 [[Agent Capability Policy Enforcement]] 增加正式 Windows-native sandbox 候选，同时保留 OpenShell/WSL2 作为历史背景。
2. **Cloudflare Skill + Codex Security 连续支持 [[Agent Verification and Audit Plane]]**：Verification 必须记录 scope、coverage、evidence 和 source revision，且 “no findings” 不能等于 PASS。
3. **REA、ArtCraft、Open Ontologies 暂留日报**：有研究价值，但证据不足以单独升级为新的长期标准。
4. **无需更新**：[[WinUI]]、[[Avalonia]]、WPF 和 [[Local-AI]] 今天没有新的可复现框架资格或本地推理 Benchmark。
