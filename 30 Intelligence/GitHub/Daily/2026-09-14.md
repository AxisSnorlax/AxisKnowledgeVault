# GitHub Trending — 2026-09-14

## 今日结论

今天真正值得保留的变化有三条：

1. **Skill Package 开始进入 Supply-chain / Trust 阶段。** `tech-leads-club/agent-skills` 今日约 +215 stars/day，不再只解决“怎么安装 Skill”，而是把 static scan、content hash、lockfile、path/symlink guard、audit trail 与人工策展加入分发生命周期。此前 [[Agent Capability Packaging]] 已确认 Skill 正在包管理化；今天新增的是“Skill 也是供应链输入，必须可验证、可审计、可回滚”。已沉淀到 [[Agent Skill Supply Chain]]。
2. **Local AI 正从 LLM Runtime 管理扩展到多模态 Engine Control Plane。** `debpalash/VoiceStudio` 今日约 +2,546 stars/day，提供 16 TTS + 11 ASR engine、Model Catalogue、GPU 自动路由、Remote Worker、OpenAI-compatible audio API、MCP、Skills 和本地桌面壳。对 [[AxisAIManager]] 的启示不是复制其产品，而是将“Engine Registry + Capability + Hardware Routing + Loopback API + Diagnostics”视为可复用控制面模式。
3. **Storage-aware Local Inference 明显加速。** `JustVugg/colibri` 今日约 +960 stars/day；相比知识库 2026-09-11 记录的约 +130/day 已出现数量级加速。其 `plan / doctor / tune`、VRAM/RAM/Disk placement、CPU/CUDA/Metal/NUMA heterogeneous execution 进一步确认：对超大本地模型，Storage Bandwidth 与 Weight Residency 应进入正式 Hardware Profile，而不只是“磁盘空间”字段。

## 今日值得关注

### tech-leads-club/agent-skills

- 方向：Agent Skills Registry / Supply-chain Security / MCP Catalog
- GitHub Trending：约 **+215 stars today**。
- 仓库：https://github.com/tech-leads-club/agent-skills
- 为什么值得看：它把 Skill 分发从“下载 SKILL.md”提升为带安全治理的 package lifecycle：100% source-only、CI static analysis、lockfile/content hashing、sanitization、path isolation、symlink guards、atomic lockfile、audit trail，并在发布前进行 Agent Skill 安全扫描。
- 另一个值得关注的点：它提供 MCP Server，通过 `search → read → fetch references` 做 progressive disclosure，不要求把整个 Skill Catalog 一次性塞进 Context。
- 对 [[AxisAgent]] 的借鉴：Skill Registry 应增加 `publisher/source trust`、`content digest`、`lock record`、`scan status`、`audit history`、`install method` 和 `rollback`；远程 Skill 默认视为供应链输入，而不是“纯文本所以天然安全”。
- 关联：[[Agent Capability Packaging]] · [[Agent Skill Supply Chain]] · [[Skills]] · [[MCP]]

### debpalash/VoiceStudio

- 方向：Fully-local Voice AI / TTS + ASR Engine Registry / MCP / Desktop
- GitHub Trending：约 **+2,546 stars today**。
- 仓库：https://github.com/debpalash/VoiceStudio
- 为什么值得看：Windows/macOS/Linux 本地应用同时管理 16 TTS、11 ASR、646-language catalogue，支持 CUDA/MPS/MLX/ROCm/CPU、Remote Workers、Model Catalogue、GPU Auto-Detect、Diagnostics、OpenAI-compatible Audio API、MCP 与 Agent Skills。
- 架构：Tauri v2 desktop shell + React/Vite + localhost FastAPI backend；Engine Adapter 与 Worker System 独立，桌面 UI 只通过 IPC / HTTP / SSE / WebSocket 驱动控制面。
- 对 [[AxisAIManager]] 的借鉴：未来如果扩展语音/视觉能力，优先抽象 `Capability → Engine Adapter → Model → Device/Backend → Health → Route`，不要为每种模态单独堆一套管理器。
- 对 [[AxisWear]] / [[AxisAgent]] 的借鉴：Audio 能力可以通过 OpenAI-compatible local API / MCP 暴露，而不是把 ASR/TTS engine SDK 直接耦合进 Agent Runtime。
- 风险：应用和模型权重许可证相互独立，必须在 Catalog 层保留 license/source metadata；不能因为应用开源就假设模型可商用。
- 关联：[[Local-AI]] · [[AxisAIManager]] · [[Professional Software Agent Surface]]
