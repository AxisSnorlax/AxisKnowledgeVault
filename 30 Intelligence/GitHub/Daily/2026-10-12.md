## 本轮长期判断

1. **供应链与执行治理分层但不脱节**：静态扫描在安装前阻止明显风险；执行时的 Runtime Policy、Approval 和 Sandbox 才决定动作是否可以实际发生。同步到 [[Agent Skill Supply Chain]] 与 [[Agent Capability Policy Enforcement]]。
2. **可检索 Memory 与可核验 Knowledge 有不同质量标准**：索引可重建，长期事实和决策需要 Source/Revision/Evidence；独立签名收据仍要配合真实语义验证。同步到 [[Agent Memory and Knowledge Lifecycle]] 与 [[Agent Verification and Audit Plane]]。
3. **Windows Computer Use 的远程 MCP Surface 必须单独加固**：本地默认只读或最小工具范围；高风险动作需显式批准，网络认证与 OS 访问控制不能互相替代。
4. 本轮没有可复现的新证据支持改变 WinUI 3、WPF、Avalonia 或 Windows Local-AI Runtime 选型，相关索引不机械更新。
