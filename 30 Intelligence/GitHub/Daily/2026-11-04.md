### P1 — agent-desktop：快照身份与动作结果成为机器合同

[README](https://github.com/vercel-labs/agent-desktop) 描述通过系统无障碍树提供 CLI/C 库；元素引用包含快照身份，界面变化或目标有歧义时需要重新观察。[v1.1.0](https://github.com/vercel-labs/agent-desktop/releases/tag/v1.1.0) 显示 11 月 3 日，记录 Windows 退出崩溃、坐标重复缩放、CRLF 输入与引用重新定位等变化。

[JSON 文档](https://agent-browser.dev/desktop/json-output) 当前合同版本为 2.6。动作可以返回 `delivered_unverified` 与不安全重试状态；快照也可能 `ok: true` 而 `complete: false`。请求参数的回显不能当作观测值，动作送达后的等待失败也不能抹掉已送达事实。

对 [[AxisAgent]] 的增量推论：保留快照及目标身份、观察完整性、送达/重试状态和验证范围；过期引用先重新定位，副作用不明时先读回。具体补充到 [[Agent Verification and Audit Plane]]，不将上游合同描述当作用户机器已验收。

Windows 边界见 [平台文档](https://agent-browser.dev/desktop/platforms/windows)：依赖用户交互桌面，Session 0、锁屏和安全桌面不在支持范围；语义 UIA 操作与物理输入模式也有区别。文档说明其行为依据适配代码与测试核对，未为该文档运行实机验证。本轮没有操作桌面或变更权限。

## C#/.NET 与本地 AI — LLPlayer 的功能级就绪

[LLPlayer README](https://github.com/umlx5h/LLPlayer) 描述 C#/WPF 播放器，支持 whisper.cpp/faster-whisper、OCR 及多种翻译服务，也列有 Ollama、LM Studio。它把 .NET Desktop Runtime 与用于 ASR/OCR 的原生依赖分开，并说明主程序启动不代表这些可选功能可用。

[v0.3.0](https://github.com/umlx5h/LLPlayer/releases/tag/v0.3.0) 页面显示 4 月 19 日，记录 .NET 10、媒体依赖、高 DPI 字幕及 ASR 默认 CPU 路径等变化，是已有版本复核。项目仍标为 beta，配置兼容性需按版本检查。

对 [[AxisAIManager]]，播放、识别、OCR、翻译和输出应分别记录引擎与就绪结果；本地识别不等于所有翻译服务离线。沿用已有能力与交付分层，本轮未安装依赖、调用模型或测试字幕准确率。

## WinUI 3、WPF 与 Avalonia

[WinUI / WinAppSDK 2.6.4](https://github.com/microsoft/microsoft-ui-xaml/releases/tag/winui3/release/2.6.4) 发布页显示 **10 月 31 日**，本次入口已不再返回此前缓存的 2.5.1。它列出文本控件在关闭阶段的访问冲突、ItemsView 滚动目标被折叠或回收时的崩溃、WebView2 初始化/焦点竞态，以及 VS Code 中生成的 XAML 成员误报修复。这是本轮新取得的既有发行证据，不改写此前采样记录。

这些为桌面工程提供了具体回归场景：关闭时尚存控件、异步滚动中的目标生命周期、初始化未完成时的焦点变化。版本已发布不等于用户项目兼容性通过，也不构成立即升级要求。

[Avalonia 12.1.5](https://github.com/AvaloniaUI/Avalonia/releases/tag/12.1.5) 继续沿用昨日记录；[WPF v10.0.13](https://github.com/dotnet/wpf/releases/tag/v10.0.13) 返回带昨日缓存，不据此保证没有其他新发布。agent-desktop 的 Windows 文档还特别区分 WPF 自动化 Peer 就绪和 WinUI/MSIX 菜单检测范围，未检测到对象不能直接解释为不存在。
