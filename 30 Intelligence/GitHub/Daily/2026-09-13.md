# GitHub Trending — 2026-09-13

## 今日结论

今天真正值得保留的变化有三条：

1. **Agent Run 正从“对话记录”继续演化成 Durable Work Record。** `superplanehq/superplane` 与 `alphaXiv/OpenResearch` 都把任务、Run、重试、Artifact、Git snapshot / worktree、Evidence 和最终结果绑定起来，强化了“可恢复执行 + 可验证证据链”这一长期方向。
2. **Professional App → Agent Surface 已经从零散案例变成稳定模式。** `pascalorg/editor` 与 `HakanSeven12/OpenCADStudio` 同日进入趋势榜；再结合此前 `dbx`、`unity-mcp`、`Unity-Technologies/skills`，建议正式采用 [[Professional Software Agent Surface]]：Domain Core + Automation Contract + MCP/Tool Surface + Domain Skills + Permission。
3. **Long-term Knowledge 开始明显强调版本、回滚和持续维护，而不只是自动生成 Wiki。** `Tencent/WeKnora` 今日约 +226/day，Wiki Mode 已包含自动维护、人工编辑、版本历史、diff/rollback；与持续高热度的 `llm_wiki` 一起强化“Knowledge 是可维护派生资产”的判断。

## 今日值得关注

### superplanehq/superplane

- 方向：AI Coding Factory / Durable Agent Workflow / Verification
- GitHub Go Trending：约 **+377 stars today**。
- 仓库：https://github.com/superplanehq/superplane
- 为什么值得看：它把 Routine Engineering 组织成 Factory → Work Order → Line → Automation → Run；每个 Run 保留 inputs、outputs、retries、cost，失败后带上下文重新进入 Agent，并持续保存 event history、execution state 和 artifacts。
- 对 [[AxisAgent]] 的借鉴：Task/Run 不应只是一段 Conversation。建议长期收敛为可恢复的 Durable Run Record，至少持有 Input Snapshot、Tool Events、Approval、Artifacts、Verification、Retry Lineage、Cost/Timing 和 Result。
- 关联：[[Agent]] · [[Agent Harness]]

### alphaXiv/OpenResearch

- 方向：Parallel Research Agents / Experiment Lineage / Local-first Workspace
- GitHub Rust Trending：约 **+120 stars today**。
- 仓库：https://github.com/alphaXiv/OpenResearch
- 为什么值得看：每个研究方向运行独立 Agent Session + Git Worktree；实验以 Git-native tree 保存，Run 获得不可变的 recorded commit archive，并把 logs、diffs、files、results、artifacts 与产生它们的工作绑定。
- 对 [[AxisAgent]] 的借鉴：如果未来支持 Subagent / Parallel Run，不要只保存聊天历史；应保存 Branch/Workspace identity、Input Snapshot、Artifact lineage 与 Verification evidence，使恢复、比较和合并有事实基线。
- 关联：[[Agent]] · [[Multi-Agent Runtime]]

### pascalorg/editor

- 方向：Local-first 3D Professional App + MCP + Domain Skills
- GitHub Trending：约 **+106 stars today**。
- 仓库：https://github.com/pascalorg/editor
- 为什么值得看：3D building editor 同时提供本地 CLI、经过认证的 MCP 服务、Local/Hosted 两类连接和可安装 Domain Skills。Skills 在使用可选字段前先检查真实 MCP tool schema，不假设源仓库最新版能力已经部署。
- 对 Axis 工业/工程软件的借鉴：Domain Skills 与 Tool Surface 应分离；连接生命周期、版本能力、Local/Hosted 模式和权限必须显式治理。
- 关联：[[Professional Software Agent Surface]] · [[MCP]] · [[Skills]]

### HakanSeven12/OpenCADStudio

- 方向：Rust CAD / GPU Desktop / Automation + MCP
- GitHub Rust Trending：约 **+102 stars today**。
- 仓库：https://github.com/HakanSeven12/OpenCADStudio
- 为什么值得看：除了 wgpu 加速 2D/3D CAD，它同时提供 one-shot CLI、persistent headless server、line-based JSON automation API、`--mcp` live editor endpoint，以及独立进程 Native Plugins。
- 对 Axis 的借鉴：对于 [[AFSCADA]] / [[AxisProtocolStudio]] 一类专业软件，应优先形成稳定、可版本化的 Automation Contract，再把同一能力映射成 MCP，而不是把 MCP 作为唯一业务 API。
- 关联：[[Professional Software Agent Surface]] · [[Desktop UI]]

### Tencent/WeKnora

- 方向：RAG + Agent + Auto-Wiki + Long-term Memory
- GitHub Go Trending：约 **+226 stars today**。
- 仓库：https://github.com/Tencent/WeKnora
- 为什么值得看：Wiki Mode 不只自动生成知识页，还提供 manual edit、revision history、line-level diff 和 rollback；同时加入 cross-session long-term memory、Skill Sandbox、MCP 与多源持续同步。
- 对 [[Axis Knowledge Vault]] 的借鉴：长期知识除 Source/Hash/Review/Refresh 外，还应该考虑 Revision、Supersedes、Rollback 与人工校正入口；“自动知识”必须可逆。

## 与 2026-09-12 相比的趋势变化

1. **Durable Run / Evidence Lineage 从隐含需求变成独立模式。** `SuperPlane` 关注 Work Order/Run/Event/Artifact/Retry，`OpenResearch` 关注 Worktree/Experiment/Immutable Commit/Evidence；二者共同强化 Agent Runtime 的“执行记录”应独立于 Conversation。
2. **专业软件 Agent Surface 明显增强。** 同一天出现两个 CAD/3D 专业编辑器的 MCP/Automation/Skills 方案，使此前 dbx/Unity 的信号达到可沉淀的程度，已新建 [[Professional Software Agent Surface]]。
3. **Knowledge 继续从“自动生成”走向“可版本治理”。** `WeKnora` 的 revision/diff/rollback 与 `llm_wiki` 的增量维护组合，说明长期知识必须支持人工修订和回滚。
4. **Skills / Spec / Agent Desktop / Local AI 的既有主线保持强势，但今天没有改变已有架构判断。**
5. **WinUI / WPF / Avalonia 今日没有足够强的新框架级信号。** 不为了日报机械修改长期 UI 索引；[[AxisAgent]] UI 框架选择仍应按同机 Qualification 决定。

## 对 Axis 的可执行事项

- [ ] [[AxisAgent]] Task/Run 模型增加 Durable Run Record 研究：Input Snapshot、Workspace/Branch、Tool Events、Approvals、Artifacts、Verification、Retries、Cost/Timing、Final Result。
- [ ] Parallel/Subagent 未来必须有独立 Workspace/Run identity 与 Artifact lineage，避免多个 Agent 共享模糊状态。
- [ ] 将 [[Professional Software Agent Surface]] 作为 AFSCADA / AxisProtocolStudio 等专业软件的 AI 接入基线：Domain Core → Automation Contract → MCP/Tool → Domain Skills → Permission。
- [ ] 高风险专业工具写操作至少区分 Read / Safe Write / High-risk Write，并由 Runtime 强制审批和审计。
- [ ] Axis Knowledge Vault 后续知识元数据可评估 `revision`、`supersedes`、`source_hash`、`reviewed_at`、`rollback` 语义。
- [ ] UI 框架本轮不作新结论；继续执行现有 Avalonia / WinUI / WPF / Web/Hybrid 同机 Benchmark 原则。
