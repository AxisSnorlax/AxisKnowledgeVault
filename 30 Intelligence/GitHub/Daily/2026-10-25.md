### P1 — Herdr：恢复需要说明恢复了什么

[仓库](https://github.com/herdrdev/herdr) 描述由后台服务管理 Agent 终端。[会话状态文档](https://herdr.dev/docs/session-state/) 区分保持原进程的 detach、重启后的布局恢复，以及依靠受支持集成恢复 Agent 原生会话；后两者不能证明此前任意进程仍在运行。恢复目录不可用时，文档要求保留错误和原目录信息。

[Windows 文档](https://herdr.dev/docs/windows-beta/) 明确列出 live server handoff 不受支持。[v0.9.5](https://github.com/herdrdev/herdr/releases/tag/v0.9.5) 发布页显示 10 月 14 日，包含 Windows 插件启动解析和非 ASCII 用户目录下会话跟踪的修复。本轮区分现行文档与该已发布版本，未证明所有文档行为均已包含在该版本中。

对 [[AxisAgent]] 的设计推论：恢复结果需要携带恢复方式、进程代次和证据来源；旧终端画面不应成为当前运行或完成状态的依据。补充到 [[Durable Agent Runtime Identity]]，不安装新运行时或改变本机调度。

### P1 — Impeccable：Skill 文本与可执行引擎分开锁定

[README](https://github.com/pbakaus/impeccable) 将产品上下文、视觉设计记录与设计命令组织为工作流，同时说明启动器可在首次运行下载独立引擎。[engine-v0.1.17](https://github.com/pbakaus/impeccable/releases/tag/engine-v0.1.17) 的发布页显示 10 月 23 日，并确认发行物是预编译引擎、供启动器和安装入口获取。

对 [[AxisAgent]] 的增量判断：Skill 源提交与最终运行的二进制不一定属于同一个版本单位，应分别追踪，并在获取或升级执行依赖时重新核对完整性及权限。具体模型加入 [[Agent Skill Supply Chain]]。项目的设计效果与检测覆盖仍是自述，本轮未安装 Skill、下载引擎或运行 hooks。

### P2 — AWS Agent Toolkit：知识包和运行工具可以独立部署

[AWS 官方仓库](https://github.com/aws/agent-toolkit-for-aws) 面向不同开发任务组合插件、Skills 和 MCP。其 Kiro 说明特别区分本地 Skills 与 AWS MCP Server，两者独立工作；[Releases 页面](https://github.com/aws/agent-toolkit-for-aws/releases) 本轮未列出发行版本，因此这里是当前仓库文档观察，不虚构版本或发布日期。

该样本支持 [[Agent Capability Packaging]] 中已有的领域合同与宿主适配分层，尚不足以再建立一套模型。Windows/.NET 客户端可借鉴知识可用性与工具连接状态分开显示；安装知识资料本身不等于获得云 API 权限。本轮未连接 AWS 账户或配置凭据。

### P2 — Git Credential Manager：升级合同包含认证体验

[GCM v3.0.1](https://github.com/git-ecosystem/git-credential-manager/releases/tag/v3.0.1) 显示 10 月 6 日，说明 3.x 转向 .NET 10、原生提前编译，并调整支持平台；3.0.1 还移除 Windows x86 发行二进制。独立平台包和 .NET tool 的运行要求应分别读取。

该发布同时强调 Microsoft 认证默认 broker 路径的变化不改变 GitHub、GitLab、Bitbucket 的认证方式。对当前 GitHub 同步问题，不能把 Azure Repos 的变化直接当作故障原因。本轮没有升级本机 GCM、修改 Git 配置或发起登录。

上述是既有发布的本轮复核。今天未取得这两个 Runtime 的可靠新增 star 窗口，趋势信号采用可核对的维护与兼容性记录，不造增长数。本轮只更新知识 Markdown，不涉及 .NET 代码、构建或测试；实际开发继续使用相应已安装 dotnet/skills。

## 长期判断

1. **恢复能力需要独立状态。** 布局、会话、进程、在途操作和完成证据分别判断，避免以旧画面充当活性证明。
2. **依赖在首次运行获取，也属于供应链。** 文本来源、启动器和最终引擎版本应可追溯，已有信任不能自动覆盖新二进制。
3. **兼容不是单一布尔值。** 宿主、操作系统、设备、认证提供方与 Runtime/EP 组合都会影响行为，验证必须限定范围。

仅向 Durable Agent Runtime Identity、Agent Skill Supply Chain 各追加一处新增证据段落；其他已覆盖主题保留原结论。
