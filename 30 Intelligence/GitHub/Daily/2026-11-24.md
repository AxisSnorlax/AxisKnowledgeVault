## P1 — Avalonia 12.2.0：新交互能力与状态一致性

[12.2.0 发行页](https://github.com/AvaloniaUI/Avalonia/releases/tag/12.2.0) 显示 11 月 23 日，包含 Fluent 2 默认主题、FlexPanel、类型化绑定表达式、Avalonia 属性源生成器和视觉几何命中测试。本轮依据 GitHub 正式发行记录，不引用未成功读取的发布博客来推导性能数字。

与 Windows 自动化直接相关的条目包括：UIA 暴露 `LabeledBy`、剪贴板被占用时重试读取、自动化 peer 移到新父节点后不再清空其父关系；双向绑定也避免把刚由源发布的值立即写回。新主题／布局与这些语义修复应分别验证。

对 [[AxisAgent]] 的研究推论：覆盖源更新和用户编辑两条绑定路径，检查重排后的自动化关系与实际命中区域，并保留剪贴板读取失败状态。新 API 或源生成器存在不自动证明现有项目可直接迁移；本轮未修改 XAML、项目依赖或运行 .NET 构建测试。增量记录写入 [[Avalonia]]。

## P2 — RustDesk：部分剪贴板写入仍需保留来源

[RustDesk 1.5.3](https://github.com/rustdesk/rustdesk/releases/tag/1.5.3) 页面显示 11 月 9 日，收录 [#16695](https://github.com/rustdesk/rustdesk/pull/16695)。PR 说明 Windows 多格式剪贴板写入可能中途失败；若用户格式已写入、所有者标记尚未写入，内容可能被监听器误当作新本地复制并回传。修复将标记先写，使这类部分结果仍能被识别。

该 PR 明确限制：标记读取失败、其他应用重写剪贴板或通知后的竞争仍是不同问题；作者没有声称完成真实剪贴板行为的自动化回归。本轮也未操作剪贴板或建立远程会话。

Windows/.NET 借鉴：对具有全局状态和多步骤写入的接口，审计来源标记与部分失败语义；编译通过不能独自证明往返同步行为正确。沿用 [[Agent Verification and Audit Plane]] 与 [[Professional Software Agent Surface]]，不重复追加一般原则。
